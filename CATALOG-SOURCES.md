# Demo catalog sources

The 23-title catalog is a manually curated 2026 snapshot, not a live release feed. Titles, cast and lead credits reference the sources below. Availability and runtime details should be checked against a real provider before production use.

Scores, season totals, episode counts, episode entries and episode runtimes are illustrative layout data. Every play button uses the same CC0 flower video.

The bundled poster and backdrop files include artwork from the original demo project and refreshed promotional posters listed below. Film artwork, titles and associated trademarks belong to their respective owners and are not covered by the implementation's MIT license; no affiliation or endorsement is implied.
